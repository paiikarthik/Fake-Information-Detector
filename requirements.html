System Prerequisites & Specifications

Project Requirements

Comprehensive overview of hardware, software, API integrations, and functional requirements needed to deploy and execute FakeXpose AI.

Hardware & Operating System

Hardware Specifications

  • Processor: Dual-Core Intel/AMD x86_64 or Apple Silicon (2.0 GHz+)
  • RAM: 4 GB Minimum (8 GB recommended for SBERT sentence embeddings)
  • Storage: 500 MB Free Disk Space (for Python packages & weights)
  • Network: Active Internet connection (for live NewsAPI & Gemini API calls)

Software Stack

  • OS: Windows 10/11, macOS 10.15+, or Linux (Ubuntu 20.04+)
  • Python Version: Python 3.10 or higher
  • Backend Framework: Flask 3.x WSGI Application
  • Authentication: Firebase Authentication Web SDK v12.13.0

Python Dependencies (`requirements.txt`)

Required Packages

Run pip install -r requirements.txt to install all necessary packages.

flask>=3.0.0 requests>=2.31.0 sentence-transformers>=2.2.2 nltk>=3.8.1 google-generativeai>=0.3.0 python-dotenv>=1.0.0

External API Requirements

Google Gemini API

Core AI

Powers claim extraction, entity parsing, and natural language explanation generation.

Key: GEMINI_API_KEY

NewsAPI

Live News

Fetches real-time news articles from verified international and regional publishers.

Key: NEWS_API_KEY

Google News RSS

Fallback

Serves as an automatic backup feed when NewsAPI daily quotas are exceeded.

No API key required

Functional & Non-Functional Specifications

Functional Requirements (FR)

  • FR-1: Extract core claim, entities, and keywords from raw text.
  • FR-2: Retrieve articles fromSnopes, Reuters, PolitiFact, and NewsAPI.
  • FR-3: Compute semantic similarity using SBERT embeddings.
  • FR-4: Calculate source credibility scores based on domain authority.
  • FR-5: Generate structured JSON response with verdict, confidence, & explanation.

Non-Functional Requirements (NFR)

  • NFR-1 (Performance): Verification response delivered under 3 seconds.
  • NFR-2 (Reliability): Graceful local fallbacks if API limits are reached.
  • NFR-3 (Security): Client-side API key encryption & server env protection.
  • NFR-4 (Usability): Responsive glassmorphism interface across mobile & desktop.
